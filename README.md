# 📚 AI-Powered Study Assistant

## 📌 Project Description

AI-Powered Study Assistant is a web-based application developed using Python, Streamlit, and Google Gemini AI.

The application helps students with learning, revision, and exam preparation by providing AI-powered study tools.

## ✨ Features

### 💬 Ask a Question
Students can ask academic questions and receive AI-generated answers.

### 📝 Summarize Notes
Students can paste their study notes and get a simple, clear, and exam-friendly summary.

### ❓ Generate Quiz
Students can enter a topic and generate five multiple-choice questions with answers.

### 🧠 Explain a Topic
Students can enter a difficult topic and receive a simple explanation with important points and examples.

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini AI
- Google GenAI Python SDK
- python-dotenv
